# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment,
personal attacks and publishing someone's private information are not accepted anywhere in this project: issues,
pull requests, discussions and reviews.

**Reporting.** If someone's behaviour here is a problem, use GitHub's **Report content** on the comment, issue or pull
request, or reach the maintainers privately through the [TelenowAI organization](https://github.com/TelenowAI) on
GitHub. Reports are kept confidential. The maintainers decide what happens next, following the Covenant's enforcement
guidelines: from a private warning up to a ban from the project.
